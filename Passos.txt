
Passo a passo para criar o repositório no GitHub e clonar no computador:
Fonte:
https://devquest.curseduca.pro/m/lessons/devquest-20-frontend-1756431088527

No GitHub
01) Cria o repositorio no GitHub:
Clicar em repositorios
Clicar em novo
Colocar nome
Adicionar um readme.md
Não selecionar o gitignore
Add license - No
Clicar em Cria reposirio.

02)No computador
Criar uma pasta do projeto no computador;
Acessar o VScode


03)No Git Bash:
Deve-se usar uma pasta que não esteja já versionada com um git
(habilitar pastas ocultas e ver se não tem a pasta "git" como subdiretorio)
(no repositore, clicar em Code, depois clicar em copiar https)
Dentro do VScode, com o terminal Git Bash aberto, digitar git clone + o url do repositorio no GitHub
Dentro do terminal, digitar cd ecommerce-suntaxwear para entrar na pasta desse projeto;
Obs.: Se não estiver no VScode, e sim no Terminal externo do Git Bash, pode-se digitar "code ." que o git vai abrir o VScode na pasta do projeto;

Usar o git clone facilita pois não é necessário fazer outros passos para conectar o diretorio e já inciá-lo corretamente versionado desde o começo.
